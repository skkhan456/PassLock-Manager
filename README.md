# <PassOP/> - Password Manager

PassOP is a sleek, modern, and fully responsive web application designed for securely storing and managing your website credentials and passwords. Built with React, Tailwind CSS, Node.js, and MongoDB.

## ✨ Features

- 🔒 **AES-256 Password Encryption**: User website passwords are stored in the database securely encrypted using AES-256-CBC algorithm.
- 📱 **Fully Responsive UI**: Mobile-compatible design tailored for smartphones, tablets, and desktop displays.
- 🔑 **Password Vault**: Store website URL, username, and password entries conveniently.
- 📋 **One-Click Copy**: Quickly copy usernames, passwords, or website URLs directly to clipboard.
- 👁️ **Show/Hide Password**: Easily toggle visibility of sensitive password fields.
- ✏️ **Edit & Delete**: Instant management and updates for saved credentials.
- 🔔 **Toast Notifications**: Crisp user feedback on actions powered by `react-toastify`.
- 🔐 **Authentication**: User Signup and Login support.

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM (v7)
- **Icons**: Lordicon & Custom Icons
- **Notifications**: React Toastify

### Backend
- **Runtime**: Node.js & Express
- **Database**: MongoDB

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) (v18+) installed on your machine.

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/skkhan456/PassLock-Manager.git
   cd PassLock-Manager
   ```

2. **Frontend Setup**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   Open `http://localhost:5173/` in your browser.

3. **Backend Setup** *(Optional for local backend development)*:
   ```bash
   cd ../backend
   npm install
   npm start
   ```
